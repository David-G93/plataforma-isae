PLATAFORMA ISAE - SERVIDORES LOCALES

Usar estos comandos desde Git Bash, dentro de la carpeta del proyecto.

INICIAR BASE DE DATOS MYSQL

bash run.sh db:start

INICIAR SERVIDORES WEB (LARAVEL + VITE)

bash run.sh dev

Abrir en el navegador:

http://127.0.0.1:8000

DETENER SERVIDORES WEB

En la terminal donde ejecutaste "bash run.sh dev", presionar:

Ctrl + C

DETENER BASE DE DATOS MYSQL

bash run.sh db:stop

COMPROBAR ESTADO DE MYSQL

bash run.sh db:status
